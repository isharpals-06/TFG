# Contributing

This is the creator's personal learning project. The creator directs creative and release decisions.

- Preserve the peaceful, mysterious fictional setting, silent traveler, Beth, and no-combat scope.
- The creator authorized implementation and invited routine creative choices that fit the original idea. Keep deeper lore and any change to the agreed inscription cliffhanger within the established brief.
- Keep changes understandable to a beginner and explain unfamiliar Godot concepts plainly.
- Do not add network services, accounts, combat, monetization, analytics, or runtime AI.
- Record all third-party asset sources and rights before inclusion.
- Do not publish or release a build without explicit creator approval.
- Do not add or run tests unless the creator asks.
