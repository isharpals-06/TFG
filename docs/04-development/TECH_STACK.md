# Technology Stack

Chosen baseline: Godot 4.7.2 stable, GDScript, Windows PC first, keyboard/controller, and local Git. GitHub remote is optional. Figma may support design planning; Canva is optional for promotion. Select a pixel editor when asset creation begins; use placeholders first.

Godot's dedicated 2D workflow and isometric tile support fit this project. Avoid beta engine releases for the learning project.

Deferred: exact pixel editor, audio editor, build automation, and distribution platform.
