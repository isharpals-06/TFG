# Technology Stack

## Current choices

- Godot **4.7.2 stable**.
- GDScript and native Godot scenes/resources.
- Windows PC first; keyboard and controller.
- Local Git; repository supplied by the creator: `isharpals-06/TFG`.
- Godot JSON save in the user-data directory.
- Generated procedural audio; no external audio library.
- Built-in image generation was used for the title-screen illustration.
- No third-party plugin or runtime service.

## Rendering

320×180 logical viewport, integer scaling, nearest texture filtering, GL Compatibility renderer. These values are a working baseline and still require display review.

## Deferred

External pixel editor, audio editor, Windows export template, signing, storefront, distribution channel, and any paid service. Do not add a dependency unless it solves a real project need.
