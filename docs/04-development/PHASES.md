# Development Phases

0. Preparation: confirm Godot and Git workflow.
1. Fundamentals: learn editor, scenes, nodes, input, signals, and GDScript.
2. Core prototype: movement, camera, interactions, one puzzle.
3. Experience slice: Beth, journal, hints, sound placeholders, environment change.
4. Production planning: review playability and settle art/story/saving needs.
5. Full production: begin only after creator approves the slice and scope.
