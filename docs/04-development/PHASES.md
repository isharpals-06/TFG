# Development Phases

1. Orientation: learn scenes, nodes, input, signals, and GDScript as each is used.
2. Core prototype: movement, camera, interaction, first observation puzzle. Source implementation present.
3. Experience prototype: Beth, journal, escalating hints, local save, settings, and ambient sound. Initial implementation present; runtime review due.
4. Route prototype: crossing, ruins, orchard, archive, observatory, three main mechanisms, optional keepsakes, and inscription cliffhanger. Initial implementation present; content depth and polish remain.
5. Full content: authored chapters, multi-step and optional puzzles, world history, side discoveries, and sufficient pacing for the 2–3 hour goal. Not complete.
6. Production and quality: final art/audio, accessibility, save recovery, and complete route review. Not complete.
7. Windows release: package, rights and attribution review, final documentation, and creator approval. Not started.
