# Roadmap

The creator is a beginner with a few hours per week. Deliver small, understandable milestones and keep the full 2–3 hour target visible. Implementation is authorized and in progress.

## Milestones

1. **Foundation** — create the Godot project, title, controls, movement, camera, local state, and first interaction loop. Initial source pass is present.
2. **Core journey loop** — add Beth, clue journal, three hint levels, first rune puzzle, save/resume, settings, and pause. Prototype source is present; runtime review is still due.
3. **Route and item loop** — connect the orchard, archive, and observatory; add the water and lens puzzles, keepsakes, item swapping, optional discoveries, and the cliffhanger. Initial route is present; content is short and unfinished.
4. **Full content** — expand the world with enough authored exploration, puzzles, story fragments, and optional discoveries to meet the 2–3 hour target. Not complete.
5. **Visual/audio production** — replace placeholder geometry, finish character and Beth animation, add area art/audio, and verify attribution. Not complete; only the title background is generated art so far.
6. **Quality and accessibility** — review controls, readability, motion, puzzle clarity, save recovery, and hint consequences in an end-to-end playthrough. Not complete.
7. **Release** — create and review a Windows export, choose a license, finish release notes, and publish only with creator approval. Not started.

## Current evidence

The Godot editor has imported the project successfully after the current code changes. This confirms project resources/scripts load in the editor; it is not a runtime playthrough and does not establish release quality. No test suite was added or run.
