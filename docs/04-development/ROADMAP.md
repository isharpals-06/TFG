# Roadmap

The creator is a beginner with a few hours per week. Deliver small, understandable milestones and keep the full 2–3 hour target visible. Implementation is authorized and in progress.

## Milestones

1. **Foundation** — create the Godot project, title, controls, movement, camera, local state, and first interaction loop. Initial source pass is present.
2. **Core journey loop** — add Beth, clue journal, three hint levels, first rune puzzle, save/resume, settings, and pause. Prototype source is present; runtime review is still due.
3. **Route and item loop** — connect the orchard, empty quarter, archive, reflection gallery, bell garden, and observatory; add water, household, lens, mirror, and bell puzzles, keepsakes, item swapping, optional discoveries, and the cliffhanger. The expanded route is present; content is still short and unfinished.
4. **Full content** — expand the world with enough authored exploration, puzzles, story fragments, and optional discoveries to meet the 2–3 hour target. Not complete.
5. **Visual/audio production** — replace remaining placeholder drawing, expand character and Beth animation, refine area art/audio, and verify attribution. Pixel-art-style backgrounds now cover the title, nine main locations, and optional garden; directional character frames and final audio remain outstanding.
6. **Quality and accessibility** — review controls, readability, motion, puzzle clarity, save recovery, and hint consequences in an end-to-end playthrough. Not complete.
7. **Release** — an initial Windows x86_64 export and preset now exist locally. Runtime review, license choice, final release notes, and creator approval remain.

## Current evidence

The Godot editor imported the project and the headless Windows release export completed successfully. These steps confirm resource import and packaging only; the game has not been launched from the exported build or reviewed in a runtime playthrough. No test suite was added or run.
