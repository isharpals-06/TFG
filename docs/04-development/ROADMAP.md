# Roadmap

Learning-first plan for a solo beginner with a few hours per week. Keep each milestone small and reviewable.

1. Orientation: learn scenes, nodes, and GDScript as they are used in the project.
2. Movement and camera: first pass is in place; refine responsiveness and readability.
3. Interaction: first pass includes inspect, pickup, activate, and target prompts.
4. Puzzle: first pass includes an inscription, symbol mosaic, three resonators, and a gate.
5. Companion/UI: Beth, journal, three hint levels, and a hint trace are prototypes.
6. End-to-end prototype: the threshold, ruins, orchard, archive, observatory, and cliffhanger are now represented in the project.
7. Content production: add enough optional discoveries and puzzle depth to meet the 2–3 hour target; refine story, art, sound, saves, and accessibility.
8. Release readiness: review the complete experience, finish Windows packaging, and prepare release materials.

Implementation is authorized and underway. Keep each milestone reviewable; do not claim completion until the full game and release materials are ready.
