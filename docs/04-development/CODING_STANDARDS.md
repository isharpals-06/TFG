# Coding Standards

Keep code clear for a beginner maintainer. Use GDScript and Godot conventions; avoid plugins without a clear need. Prefer clear names, small scripts, typed variables where useful, and scenes/resources for reusable content. Use signals where they reduce coupling. Store content IDs separately from display text. Comment unusual reasoning, not every line. Save Git checkpoints at working milestones. Do not add or run tests unless the creator asks for testing or verification.
