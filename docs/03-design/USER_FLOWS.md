# User Flows

## Start and resume

Title → Begin → choose Moss or Mist mantle → crossing scene. Continue loads local state and returns to the current area's entry point. Pause → Resume or Save and Return to Title.

## Explore

Move → approach a nearby target → read its icon and action prompt → examine, take, activate, or use selected item. Small status text and world response explain the result.

## Puzzle

Observe → examine a clue → clue enters the journal → experiment freely → receive feedback → solve → visible mechanism/route changes. Puzzle state persists when saved.

## Hints

H → select level 1, 2, or 3 (or press its number while the panel is open) → receive Beth's hint. Every request adds a stronger echo over time. Solving a puzzle clears local intensity; the world-wide trace remains.

## Keepsakes

F to take → if a slot is free, the item is added and selected as needed → if full, I opens an exchange list → choose a non-story keepsake to replace → I opens inspection and selection → U uses the selected item on a compatible target.

## Journal

Clue discovery → brief sound/highlight → J opens the clue list → player connects clues without an answer being supplied.
