# User Flows

## Start and resume

Title → Begin → choose Moss or Mist mantle → crossing scene. If a save already exists, the game asks before replacing it. Continue loads local state and restores the latest checkpoint. Pause → Resume or Save and Return to Title.

## Main route and optional branch

Crossing → ruins → orchard → empty quarter → archive → reflection gallery → bell garden → highland steps → observatory. Restore the orchard water, return household objects to their village niches, and descend through the well to continue. After restoring the water, the player may visit the optional reed causeway, follow its seven-stone pattern, record a small valley memory, then enter the village or return to the orchard. In the archive, the mirror shard reveals a fourth lens path; aligning it opens a shelf with an independent keeper's note, while the main stair remains open. Planting the pale seed opens the optional quiet garden; solve its chime puzzle or return to the orchard at any time. In the observatory, a keeper's chart gives the directions for an optional three-arm astrolabe. Aligning it opens a drawer with a weather ledger; the inscription remains available at all times.

## Explore

Move → approach a nearby target → read its icon and action prompt → examine, take, activate, or use selected item. Small status text and world response explain the result.

## Puzzle

Observe → examine a clue → clue enters the journal → experiment freely → receive feedback → solve → visible mechanism/route changes. Puzzle state persists when saved.

## Hints

After Beth wakes, H → select level 1, 2, or 3 (or press its number while the panel is open) → receive Beth's hint. Before then, the quiet gives no answer and adds no penalty. Every request adds a stronger echo over time. Solving a puzzle clears local intensity; the world-wide trace remains.

## Keepsakes

F to take → if a slot is free, the item is added and selected as needed → if full, I opens an exchange list → choose a non-story keepsake to replace → I opens inspection and selection → U uses the selected item on a compatible target.

## Journal

Clue discovery → brief sound/highlight → J opens the clue list → player connects clues without an answer being supplied.
