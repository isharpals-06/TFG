# User Flows

- Explore: enter area → follow environmental cue → interaction icon → examine → clue may enter journal.
- Puzzle: observe → experiment freely → receive feedback → optionally ask Beth for one of three hints → solve → environment changes and Beth reacts.
- Inventory: pick up → swap if full → inspect → select item → use on compatible object.
- Journal: clue discovered → page animates entry → player connects clues independently.
- Consequence: hints build local effect → world/Beth signal it → mostly recedes after puzzle while a small trace can persist.
