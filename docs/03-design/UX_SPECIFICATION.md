# UX Specification

Principles: invite curiosity, let environments carry guidance, make interactions clear without clutter, allow safe experimentation, make hints optional and in-world, and give puzzle solutions readable feedback.

Approach can reveal object detail; a small icon marks interactables. Examine, pick up, activate, and item-use are intentional. Wrong attempts give gentle feedback without consuming resources.

Camera reframes gradually, has limited zoom, rotates among consistent isometric views with optional snap behavior, and adjusts for occlusion. Provide reduced-motion settings.
