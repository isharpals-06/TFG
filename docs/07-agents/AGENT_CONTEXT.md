# Agent Context

## Creator

Beginner, a few hours per week, personal learning project. The creator authorized full implementation and asked for routine creative choices to be made independently; ask only about material decisions. Use multiple choice if a question is necessary.

## Vision

The Forgotten World: peaceful, mysterious, nostalgic, occasionally melancholic fictional medieval fantasy. Isometric pixel art, no combat, 2–3 hour target, silent traveler, Beth as playful glowing spirit orb. Environmental storytelling carries the experience.

The village well also has an optional saved bowl → lamp → bell memory sequence, unlocked by reading the waterworks bowl record, Archive last entry, and bell keeper's list. It reveals ordinary valley history only and does not explain the traveler's past.

## Story

The opening combines a crossing and the discovery of an unusual medallion. The traveler enters abandoned ruins and wakes Beth. A previously discovered inscription starts as gibberish and animates into a hidden message near the ending. The reveal is subtle. The cliffhanger message “YOUR HAND HAS BEEN HERE BEFORE.” is the first clear sign of the traveler's connection to the world's past. Do not explain the full connection in this release.

## Gameplay

Exploration, fair observation-led puzzles, safe experimentation, occasional multi-step mechanisms, optional clues, and a clear main route. Four provisional inventory slots with safe swapping. Journal clues are recorded but not connected for the player. Beth offers three hint levels; each use increases the journey-wide echo, while solving a puzzle clears local intensity. The echo affects Beth, the environment, optional findings, and the ending without hard-locking progress.

## Technical baseline

Godot 4.7.2 stable, GDScript, Windows PC, keyboard/controller, 320×180 logical canvas, local JSON save, Git repository supplied by creator. Figma/Canva are optional. Original generated backgrounds cover the title and current route; traveler and Beth have generated sprite assets with simple in-engine motion. Puzzle marks and interface pieces are drawn in GDScript. No third-party game assets are included.

## Status

The twelve-location route now includes the old waterworks, with a saved four-mark wheel sequence connecting the orchard to the village; it also has a map chamber between Archive and reflection gallery with a saved spring-bridge-village sequence, plus a highland refuge after Bell Court with three ordinary-life records and safe return/onward paths. The waterworks also opens an optional lower cistern with a saved four-turn valve pattern, water-sharing ledger, and optional river-glass clue. Optional branches include the garden, reed causeway, west-house reading room, and lower cistern; the causeway includes short stepping-stone hops, and the reading room has a saved three-marker arrangement, three hint levels, and two ordinary-history records. Optional puzzles include the archive mirror path and village-well gathering sequence. The observatory's chart and astrolabe are required before the inscription; the weather ledger remains optional. The project has ten main puzzle mechanisms, six optional puzzles, hint-dependent Bell Court and High Steps variants, keepsakes, field journal, companion hints, and local save/settings systems. Optional environmental records trace the valley's evacuation without explaining the traveler's past. The map chamber, lower cistern, village gathering sequence, highland refuge, and revised observatory sequence have not had runtime reviews; the 2–3 hour content target, full runtime review, accessibility review, final audio, and Windows release remain incomplete. Do not claim release readiness until those gaps are closed.
