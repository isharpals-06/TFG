# Security and Privacy Design

- No network service, accounts, analytics, telemetry, or remote data collection.
- Saves stay in the operating system's Godot user-data directory and contain game state and settings only.
- Saves are local progress, not a security boundary. Do not store credentials or personal data.
- Track sources and license terms for third-party code, fonts, audio, and art.
- Review downloaded assets/scripts before adding them.
- The repository excludes the downloaded Godot editor and generated import/cache files.
- Before distribution, review the generated assets and all third-party contributions for rights and attribution.
