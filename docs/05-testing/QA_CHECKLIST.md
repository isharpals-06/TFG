# QA Checklist

Future release review; not performed:
- [ ] Main route completes without hints.
- [ ] Hint use never hard-locks main progress.
- [ ] Save/load preserves puzzles, clues, inventory, and hint state.
- [ ] Keyboard/controller mappings and remapping work.
- [ ] Text, subtitles, reduced motion, and visual cues are reviewed.
- [ ] Pixel art scales cleanly.
- [ ] Placeholder material is intentionally resolved.
- [ ] Third-party licenses and attributions are recorded.
- [ ] Full beginning, middle, and ending are playable.
