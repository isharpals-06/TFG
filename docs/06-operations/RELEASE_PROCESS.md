# Release Process

No release has been made. When the project is ready:

1. Review the 2–3 hour route from a clean save.
2. Confirm save/resume, controller, display scale, reduced motion, hints, and inventory swapping.
3. Resolve every placeholder and rights/credit entry.
4. Choose the code and asset license with the creator.
5. Export Windows using the matching Godot version and templates.
6. Test the exported build outside the editor on a clean user profile.
7. Prepare version number, changelog, screenshots, and credits.
8. Ask the creator to approve the concrete release candidate.
9. Publish only after explicit approval and record the release tag/artifact location.
