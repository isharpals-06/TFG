## Release preparation

1. Finish the 2–3 hour route and art/audio.
2. Complete runtime, accessibility, save/resume, and rights reviews.
3. Install the matching Godot 4.7.2 Windows export templates.
4. Create a Windows desktop export preset and export a clean build.
5. Test the exported build on a Windows system without the editor.
6. Choose the project license and distribution channel with the creator.
7. Prepare final release notes and credits; obtain creator approval before publishing.

Do not include editor binaries, Godot cache/import files, local save data, or secrets in the release package.
